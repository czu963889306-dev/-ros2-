# LEAP ROS2 开源机器人

这是 LEAP ROS2 开源机器人的资料索引仓库。

本仓库保留硬件相关资料，软件源码已拆分到独立仓库维护，方便按模块拉取、更新和复用。

## 仓库索引

| 模块 | 说明 | 源码仓库 |
| --- | --- | --- |
| 单片机驱动 | 机器人底层单片机控制代码 | [leap_ros_mcu_driver](https://github.com/czu963889306-dev/leap_ros_mcu_driver) |
| WiFi 图传 | ESP32-S3 WiFi 摄像头图传源码 | [esp32_s3_wifi_camera](https://github.com/czu963889306-dev/esp32_s3_wifi_camera) |
| ROS 功能包 | ROS2 工作空间与功能包源码 | [leap_ros_ws](https://github.com/czu963889306-dev/leap_ros_ws) |

## 本仓库内容

- `硬件/`：原理图、BOM 物料清单、嘉立创工程文件、3D 打印外壳等硬件资料。
- `README.md`：项目资料索引。

## 使用方式

1. 根据需要先查看本仓库中的硬件资料。
2. 按模块进入上方源码仓库，分别获取单片机、WiFi 图传和 ROS 功能包代码。
3. 按各源码仓库 README 或说明文档完成编译、烧录和运行。
